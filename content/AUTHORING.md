# Content notes

Add a project by creating `content/projects/<slug>.mdx` and, when you have them, files in `public/projects/<slug>/`. Add a note by creating `content/writing/<slug>.mdx`. Do not add a React component for either one.

Leave a field out when you do not have the fact. The page hides empty sections. Do not invent metrics, model names, deployments, or repository URLs.
