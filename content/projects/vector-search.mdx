overview: |
  These are small, deliberate experiments with the retrieval layer that sits underneath RAG. They run over a handful of sample documents, not a production dataset. The aim was to understand how vector stores and retrievers behave before building on them.
solution: |
  The vector store experiment uses a persistent Chroma collection with OpenAI embeddings. It adds documents with metadata, runs similarity search with and without scores, filters by metadata, and updates and deletes documents by ID.

  A second set of scripts, in the [langchain-retrievers](https://github.com/uneiz1103/langchain-retrievers) repository, compares retrieval strategies. They cover a plain vector-store retriever, maximal marginal relevance (MMR) for more diverse results, a multi-query retriever that has an LLM rephrase the question, and contextual compression, which trims retrieved passages to the relevant sentences.
lessons: |
  Plain similarity search can return near-duplicate passages. MMR trades a little relevance for variety. Multi-query retrieval helps when a question can be phrased several ways, and contextual compression reduces noise before text reaches the prompt. Each of these costs extra computation or extra LLM calls.
